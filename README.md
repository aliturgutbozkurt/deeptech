## 🌟 Proje Özeti / Project Overview

**Aptala Anlatır Gibi Derin Teknolojiler (Deeptech Masterclass)**; kariyerini geleneksel SaaS/Web yazılımının ötesine taşıyıp geleceğin sınır teknolojilerinde (*Frontier Engineering*) kurmak isteyen mühendisler, araştırmacılar ve girişimciler için hazırlanmış **500 derslik** devasa bir başvuru kaynağıdır.

Müfredat, **Kuantum Hesaplama**, **Yarı İletken Fiziği**, **Sentetik Biyoloji**, **Nükleer Füzyon**, **Nöromorfik Çipler**, **Otonom Robotik**, **Beyin-Bilgisayar Arayüzleri (BCI)**, **Uzay İtki Sistemleri** ve **İleri Malzemeler** gibi 50 kritik derin teknoloji disiplinini kapsar.

### 🎯 Temel Özellikler / Key Pillars:
1. **Explain Like I'm 5 (ELI5) Pedagojisi**: En karmaşık Schrödinger dalga denklemleri, GAAFET transistör sızıntıları veya tokamak plazma kararsızlıkları günlük hayatın eğlenceli benzetmeleriyle sadeleştirilir.
2. **Uçtan Uca Çift Dilli (Bilingual TR & EN)**: Her dersin mimari şeması, ELI5 anlatımı, teknik mühendislik analizi, risk uyarıları ve altın çıkarımları yan yana Türkçe ve İngilizce olarak sunulur.
3. **Uygulamalı Kod & Simülasyonlar**: Python, Rust, C++, Qiskit, CUDA/Triton, BioPython ve ROS 2 kullanılarak yazılmış gerçekçi simülasyon kodları.
4. **551 Tamamlanmış PDF Yayını**:
   - 📕 **1 Master Mega-Kitap PDF** (`output/book/Deeptech_Masterclass_ELI5.pdf` — 18.6 MB, 550+ Sayfa)
   - 📦 **50 Bölüm Kitapçığı PDF** (`output/modules/module_01.pdf` ... `module_50.pdf`)
   - 📄 **500 Bireysel Ders PDF** (`output/individual/lesson_001.pdf` ... `lesson_500.pdf`)
5. **Etkileşimli Web Companion Reader (`web/`)**: Anlık arama (instant search), tek tıkla TR/EN/Çift Dilli görünüm geçişi, kod kopyalama ve PDF indirme merkezi.
6. **4 Çalıştırılabilir Referans Uygulama (`examples/`)**: Kuantum Bell State, GPU SIMD hızlandırma, CRISPR sgRNA tasarımcısı ve 6-DOF Robotik Ters Kinematik.

## 🛠️ Çalıştırılabilir Referans Uygulamalar / Runnable Examples

Repo içerisinde, teoriyi pratik endüstriyel kodlamayla birleştiren 4 adet hazır ve bağımsız Python betiği bulunmaktadır:

### 1. Kuantum Dolanıklık Simülatörü (`examples/quantum/bell_state_simulation.py`)
2-Qubit durum vektörü evrimi, Hadamard & CNOT kapıları ve Monte Carlo Born kuralı ölçüm simülasyonu:
```bash
python3 examples/quantum/bell_state_simulation.py
```

### 2. GPU SIMD & GEMM Karşılaştırma Motoru (`examples/gpu_cuda/parallel_gemm_benchmark.py`)
Skalar CPU döngüsü vs Vektörize SIMD paralelliği ve GPU Shared Memory Tiling matris çarpımı:
```bash
python3 examples/gpu_cuda/parallel_gemm_benchmark.py
```

### 3. CRISPR-Cas9 sgRNA Rehber Tasarımcısı (`examples/bio/crispr_guide_designer.py`)
DNA hedeflerinde SpCas9 PAM (5'-NGG-3') tarayıcısı, GC oranı termodinamik kontrolü ve Poly-T terminasyon filtresi:
```bash
python3 examples/bio/crispr_guide_designer.py
```

### 4. 3-DOF Robotik Manipülatör Ters Kinematik Çözücüsü (`examples/robotics/inverse_kinematics_controller.py`)
İleri kinematik (FK) ve Damped Least Squares Jacobian Ters Kinematik (IK) yörünge izleme çözücüsü:
```bash
python3 examples/robotics/inverse_kinematics_controller.py
```
